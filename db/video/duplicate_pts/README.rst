``h264_nonref_dup_pts.ts`` is an MPEG-TS clip, cut from the Sintel trailer, in which pairs of frames
share a pts. It is generated, and checked, by ``../mpegts/generate.py``; see ``../mpegts/README.rst``
for what the file contains and how to regenerate it.
