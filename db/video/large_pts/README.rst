``h264_large_pts.ts`` is an MPEG-TS clip, cut from the Sintel trailer, whose timestamps do not fit in
a signed 32-bit integer. It is generated, and checked, by ``../mpegts/generate.py``; see
``../mpegts/README.rst`` for what the file contains and how to regenerate it.
